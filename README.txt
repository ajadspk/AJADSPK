AJADS — GITHUB PAGES READY PACKAGE
==================================

This package is ready for GitHub Pages.

IMPORTANT:
- index.html is already at the repository root.
- assets/images contains images.
- assets/posters contains video poster images.
- assets/videos contains all website videos.
- The complete project is about 44 MB, so the total size is NOT a problem.
- No individual file is over GitHub's normal 100 MB single-file limit.
- The final portfolio is curated into 4 projects:
  1. Louis Vuitton + blue-shirt campaign
  2. Rolex watch
  3. Biscuit + chocolate campaign
  4. Gym branding + hair tonic campaign

BEGINNER GITHUB DESKTOP METHOD
------------------------------
1. Extract this ZIP.
2. Open GitHub Desktop.
3. File > Add Local Repository.
4. Select the extracted AJADS_GITHUB_READY folder.
5. If asked to create a repository, create it.
6. Click Publish repository.
7. Keep the repository Public if you want a public portfolio.
8. On GitHub open Settings > Pages.
9. Under Build and deployment choose:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
10. Click Save.
11. Wait for GitHub Pages to finish deploying.
12. Open the generated https://YOUR-USERNAME.github.io/REPOSITORY/ address.

DO NOT upload the ZIP itself to GitHub.
Upload/publish the EXTRACTED FOLDER CONTENTS through GitHub Desktop.

IF VIDEOS OR IMAGES DO NOT APPEAR
---------------------------------
Do not rename or move the assets folders after publishing.
The website expects:
assets/images/
assets/posters/
assets/videos/

The project already uses relative paths suitable for GitHub Pages.
